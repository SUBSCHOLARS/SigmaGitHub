# ΣIGMA -シグマ- ルールブック(マークダウン版) version 1.1
## 1. ゲームの目的
- プレイヤーは管理局「BUREAU」が提示する「**トレンド**(場の数字)」に、自身の「**社会的価値**(手札の合計値)」を一致(**マッチ**)させることを目指します。
- これはラウンド制のゲームであり、最終的に最も多くの「**クレジット**(ポイント、単位はNullにかけてNullerの予定。Bribeのカードデザインにも表れている)」を獲得したプレイヤーが勝者となる。
## 2. ゲームの準備
- **プレイヤー**: 3人(現在はプレイヤー1人, CPU2人だが、今後はマルチプレイヤーも検討)
- **デッキ**: 現状は全120枚のカードをシャッフルして「山札」とします。
- **配布**: 各プレイヤーに手札を7枚ずつ配ります。
- **開始**: 山札から「数字カード」が1枚捲られ、最初の「馬のカード」となり、その数字が最初の「トレンド」となります。
## 3. あなたのターンにできること
あなたのターンが回ってきた時、以下の**2種類**のアクションから**必ず1つ**選択します。
- カードをプレイする:
  * あなたの手札からカードを1枚選び、クリックして「場」に出します。
  * カードを出すと、あなたのターンは終了し、カードに効果がある場合は効果が発動します。
- カードをドローする:
  * 画面上の「山札（ドローボタン）」をクリックします。
  * あなたは山札からカードを1枚手札に加え、あなたのターンは即座に終了します。(この行動では「セルフマッチ」は発生しません。)
## 4. カードをプレイするルール
場に出すカードは、現在「場の1番上にあるカード」に対して、以下のいずれかの条件を満たしている必要があります。
- **ワイルドカード**: **Bribe(賄賂)**, **Censor(検閲)**, **Interrogate(尋問)**は場のカードに関係なく、**いつでも**出すことができます。
- **セクター(絵柄)一致**: 場のカードとセクター(絵柄)が同じカードを出すことができます。
- **種類(効果)一致**: 場のカードと**効果**が同じカードを出すことができます。（例: 場がSuspendの時に、別の絵柄のSuspendを出す、など。）
- **数字(トレンド)一致**: あなたが出すカードが「数字カード」で、その数字が現在の「**トレンド値**」と一致していれば出すことができます。(例: Bribeの効果でトレンドが「5」になっている時、Eye_5やGear_5を出すことができます。)
## 5. 勝利条件(マッチ)
誰かがカードを出すか、プレイヤーがドローした直後に、全プレイヤーの勝利判定が行われます。
- **トレンドライド**:
  * **最優先**で判定されます。
  * カードを出した人**以外**のプレイヤーの「手札合計値」と「場のトレンド値」が一致した場合、そのプレイヤー(複数可)が勝利します。
- **セルフマッチ**:
  * トレンドライドが発生しなかった場合のみ判定されます。
  * カードを出した(またはドローした)**本人**の「手札合計値」と「場のトレンド値」が一致した場合、そのプレイヤーが勝利します。
- **テンホウ**:
  * 最初に自動的に出されるカードにより構成される場のトレンド値と、自分の手札の合計値が一致していた場合、即座に勝利します。(これはトレンドライドの特殊な場合となります。)
- **勝利の規則**:
  * Bribe(賄賂)のカードを出してセルフマッチすることはできません。（ターンが強制的に終了します。）
  * 手札の合計値と場のトレンドが両方とも0の場合、マッチとは見做されず、勝利できません。
## 6. カード効果の詳細
- **数字カード(1~10, -3~-1)**
  * 場に出すと、currentTrendValue(トレンド値)がそのカードの数字に更新されます。
- **Audit(監査)**/**Suspend(停職)**/**Reject(差し戻し)**:
  * 場に出すと、トレンド値がそのカードの数字に更新されます。数価は一律で10となっています。
  * その後、ターンが次の人に映る際に、効果が発動します。
    * Audit: 次の人がAuditを持っていない/持っているが出さなかった場合は2枚ドローします。
    * Suspend: 次の人が1回休み(スキップ)になります。
    * Reject: ターンの進行順が逆になります。
- **Censor(検閲)**
  * いつでも出すことができます。
  * 場に出した際、他のプレイヤーを一人選び、そのプレイヤーの手札をすべて開示させます。
  * 次の人がカードの絵柄、数字を決定します。
- **Interrogate(尋問)**
  * いつでも出すことができます。
  * 場に出した際、他のプレイヤーを一人選び、そのプレイヤーの手札の内、最大のものを開示させます。
  * 次の人がカードの絵柄、数字を決定します。
- **Bribe(賄賂)**
  * いつでも出すことができます。
  * 場に出した際、1~6の中から数字を選んでトレンド値を書き換えることができます。
  * 設定した数字でセルフマッチすることはできません。
  * 絵柄を持っており、出した際の場の絵柄はこの絵柄が適用されます。
